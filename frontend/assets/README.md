## Required Assets for App Store

Replace these placeholder files before submitting to App Store:

- `icon.png` — 1024x1024 px, no transparency, no rounded corners (iOS adds them)
- `splash.png` — 1284x2778 px (iPhone 14 Pro Max), centered logo on #1a1a2e background
- `adaptive-icon.png` — 1024x1024 px for Android adaptive icon (with safe zone)

### Quick generation (using any image editor):
1. Create 1024x1024 canvas, background #1a1a2e
2. Add your logo/icon centered
3. Export as PNG
